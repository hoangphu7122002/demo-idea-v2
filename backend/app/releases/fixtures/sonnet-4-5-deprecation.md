# Claude Platform release notes: Claude Sonnet 4.5 deprecation

Sources (copied verbatim):
- https://platform.claude.com/docs/en/release-notes/overview
- https://platform.claude.com/docs/en/about-claude/model-deprecations

## September 30, 2026

We announced the deprecation of the Claude Sonnet 4.5 model (claude-sonnet-4-5-20250929), with retirement on the Claude API scheduled for November 30, 2026. We recommend migrating to Claude Sonnet 5.5. Read more in Model deprecations.

## September 28, 2026

We've launched Claude Sonnet 5.5 (claude-sonnet-5-5). It's available on the Claude API, Claude in Amazon Bedrock, Claude Platform on AWS, Claude on Google Cloud, and Claude in Microsoft Foundry.

## Model deprecations: 2026-09-30, Claude Sonnet 4.5 model

On September 30, 2026, Anthropic notified developers using Claude Sonnet 4.5 of its upcoming retirement on the Claude API.

| Retirement date | Deprecated model | Recommended replacement |
| --- | --- | --- |
| November 30, 2026 | claude-sonnet-4-5-20250929 | claude-sonnet-5-5 |
